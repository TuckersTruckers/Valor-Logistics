# Valor Logistics LLC – VALOR Website

Simple static website recreating the company flyer.

## Deploy to GitHub Pages

1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Source**, select the `main` branch and `/ (root)`.
4. Save. Your site will be available at:
   `https://YOUR-USERNAME.github.io/REPO-NAME/`

## Customization

- Update the contact address, phone, and email in `index.html`.
- Replace the shield logo with a real logo image if desired.
- Colors and fonts can be adjusted in the `:root` CSS variables.
